# 大可咖啡 RoastCommons — downloads

Installers for the RoastCommons beta. **Download page: https://roastcommons.github.io/download**

- Mac: [`RoastCommons-mac.dmg`](https://github.com/RoastCommons/releases/releases/latest/download/RoastCommons-mac.dmg) (macOS 12+)
- Windows: [`RoastCommons-windows.exe`](https://github.com/RoastCommons/releases/releases/latest/download/RoastCommons-windows.exe) (Windows 10+)

Each release also carries the same files with the version in their names, and `SHA256SUMS.txt`, which the app's
updater checks before it installs anything. This repository holds only releases; the app updates itself from here.
